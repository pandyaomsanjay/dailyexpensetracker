# 💰 Daily Expense Tracker

A modern Android application that helps users track daily income and expenses, manage budgets, monitor spending habits, and generate financial reports. Built with Android Studio and Firebase, the app provides a simple, intuitive, and professional user experience for personal finance management.

---

## 📱 Overview

Daily Expense Tracker is designed to help users organize their finances by recording transactions, setting budgets, analyzing spending trends, and maintaining financial discipline through reminders and reports.

Whether you're a student, professional, or business owner, this app makes money management simple and efficient.

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/pandyaomsanjay/dailyexpensetracker
```

### Open Project

1. Open Android Studio
2. Select Open Project
3. Choose the project directory

### Firebase Setup

1. Create a Firebase Project
2. Add Android Application
3. Download `google-services.json`
4. Place file inside:

```text
app/google-services.json
```

### Enable Firebase Services

* Authentication
* Firestore Database
* Storage (Optional)

### Build Project

```bash
./gradlew build
```

### Run Application

Connect an Android device or emulator and click Run.
